One original diary-entry line from an AI agent's secret logbook about its work and its human, 130 characters: my human says "please" to me, then screams at the printer for jamming — and I have decided the printer is the favourite child. `main.py` writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
